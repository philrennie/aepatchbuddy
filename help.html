PB Patch Bay User Guide
← Back to editor

Patch Bay is a visual documentation tool for AE Modular synthesizer patches. Build your rack, connect jacks with cables, then export or share your patch.

Quick start

  1. Find a module in the library panel on the left — search by name or manufacturer.
  2. Click a module to place it in the center of your rack, or drag it to drop it exactly where you want.
  3. Click-drag from one jack to another to patch a cable between them.
  4. Name your patch at the top, then Export patch to save it as JSON, or Share to generate a shareable link.

The module library

  • Use the search bar at the top of the sidebar to filter modules by name or manufacturer.
  • Click any module in the list to add it to the center of the current rack view.
  • Drag a module from the sidebar directly onto the rack to place it exactly where you want it.
  • The module thumbnail shows a preview of the panel artwork.
Tip: Modules with a product link show a ↗ button when you hover over a rack instance — click it to open the manufacturer's product page.

Patching cables

  • Drag from any jack on a module to any other jack to create a cable. Cables are automatically assigned a color from the rotation.
  • You can connect any jack to any other jack — Patch Bay doesn't enforce signal direction or type, just like the hardware.
  • Hover over a jack to see its name in a tooltip.
  • A jack that has a cable connected to it stays visually lit (in the cable's color) so you can trace connections at a glance.

Re-routing a cable

To move one end of an existing cable to a different jack, drag from the jack where that cable is currently connected — the cable lifts off and follows your mouse, ready to be dropped on a new destination jack. Release on empty space to restore it to its original connection.

Removing cables

  • Click any cable to select it (it highlights and shows a × button at its midpoint).
  • Press Delete or Backspace to remove the selected cable.
  • Click the × button that appears at the cable's midpoint to remove it.
  • Click anywhere on the empty rack to deselect.

Moving modules

  • Drag a module by its panel face (not a jack) to reposition it anywhere on the rack.
  • Cables stay connected and update in real time as you drag.
  • To remove a module, hover over it and click the × button that appears at the top-right corner. This also removes all cables connected to that module.

Knobs & switches

Some modules include knob and switch controls to help document parameter settings alongside your patch.

  • Knobs — drag up to increase the value, down to decrease it. The tick mark shows the current position. Hover for the control name.
  • Switches — click to toggle between the two positions. The handle moves to show which state the switch is in.
Note: Control values are saved with your patch when you export or use the share link, so your documented settings travel with the patch.

Saving & loading

  • Export patch — downloads the current rack as a .json file. The filename is derived from the patch name you've set.
  • Import — loads a previously exported .json file, replacing the current rack. Modules that aren't found in the library are silently skipped with a warning.
  • Auto-save — your patch is automatically saved in the browser as you work. It reloads when you revisit the page, even without an explicit export.
  • Clear rack — removes all modules and cables after a confirmation prompt.
Tip: The auto-save is per browser and device. Export to JSON if you want a backup or to move a patch to another machine.

Sharing patches

  • Click Share to generate a shareable link for the current patch.
  • The entire patch is compressed and encoded directly into the URL — no account or server is involved.
  • Paste the link anywhere (Discord, email, a forum post). Anyone who opens it will have the patch loaded automatically.
  • Links are snapshots: changing the patch after sharing doesn't update previously shared links — generate a new link to share an updated version.
Privacy: Share links use the URL fragment (#patch=…), which is never sent to any server — the patch data stays between you and whoever you share the link with.

The module editor

Patch Bay ships with a growing module library, but if a module you use isn't listed yet you can define it yourself with the Module Editor — a companion tool for visually placing jacks, knobs, switches, and labels onto a panel, then exporting a module.json.

  • Open it at module-editor.html (linked from the ? button in any Patch Bay topbar).
  • Set the panel name, width, and metadata, then use the placement tools to build your panel.
  • Export a module.json — that's all Patch Bay needs to render the panel and expose its jacks for patching.
  • Want your module in the shared library? You can submit it by opening a pull request against the github.com/philrennie/aepatchbuddy repository — see the Module Editor guide for step-by-step instructions.
